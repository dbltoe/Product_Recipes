# Product Recipes settings

**Configuration → Product Recipes**. An upgrade never changes a value you've set.

| Key | Setting | Default | What it does |
|---|---|---|---|
| `PRODUCT_RECIPES_STATUS` | Enable Product Recipes? | true | Master switch for the storefront. Off: the Recipes page sends visitors home and no links show. The admin keeps working. |
| `PRODUCT_RECIPES_PER_PAGE` | Recipes per page | 12 | Recipes listed per page on the index. |
| `PRODUCT_RECIPES_SHOW_PRICES` | Show product prices? | true | Each linked product's price (your store's price-visibility rules still apply). |
| `PRODUCT_RECIPES_SHOW_STOCK` | Show stock? | true | In stock / Out of stock beside linked products. |
| `PRODUCT_RECIPES_ADD_TO_CART` | Allow adding ingredients to the cart? | true | Quantity boxes, per-line Add to Cart and Add Checked to Cart. |
| `PRODUCT_RECIPES_OUT_OF_STOCK` | Out-of-stock ingredients | Show | Show: link and price stay; can be added only if the store allows out-of-stock checkout. Text Only: plain text. |
| `PRODUCT_RECIPES_SHOW_METHOD_FILTER` | Show the cooking-method filter? | true | The method links at the top of the index. |
| `PRODUCT_RECIPES_INFO_SIDEBOX_LINK` | Add a Recipes link to the Information sidebox? | true | Zen Cart 2.0.0 and later. |
| `PRODUCT_RECIPES_SIDEBOX_MAX` | Recipes sidebox: how many recipes | 3 | Newest recipes in the Recipes sidebox. |
| `PRODUCT_RECIPES_IMAGE_WIDTH` | Thumbnail width (pixels) | 220 | Picture width on the index. |
